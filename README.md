# Words

An AI-powered linguistics platform built with Streamlit.

## Features

- Dictionary definitions
- Morphological analysis
- Sentence analysis
- Etymology explorer
- Word relationships
- AI explanations
- WordNet integration
- Datamuse integration

## Tech Stack

- Python
- Streamlit
- spaCy
- NLTK
- Groq
- Plotly
- NetworkX
